// CONFIGURACIÓN DE CONTROLES

Exploración: W acelera, S o Espacio frena, A/D gira y Q/Z sube o baja el morro. Shift activa el turbo. Arrastra para mirar; usa la rueda para acercar la cámara. En móvil: joystick para avanzar/girar, arrastre derecho para mirar.

La nave apunta hacia donde mirás: en PC, movés el mouse (W/S siguen acelerando y frenando); en celular, el joystick gira y empuja, y arrastrás la cámara para subir o bajar.

W/S inclina el morro, A/D gira, Q/Z alabea. Shift acelera y Ctrl frena (reasignables); Espacio también frena. E queda reservado para interactuar.
